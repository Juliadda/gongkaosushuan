# 公考速算练习

一个帮助提升公务员考试数学运算速度的在线练习工具。

## 功能特性

- 🎯 **凑整百练习**：减法凑整百训练（如 100-23, 300-232）
- 🎯 **凑整十练习**：加减法凑整十训练
- 📊 **实时反馈**：提交后立即显示对错并自动跳转下一题
- ⏱️ **计时统计**：记录练习时间和正确率

## 技术栈

- React 18 + TypeScript
- Vite 6
- TailwindCSS

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 部署

本项目已配置 Cloudflare Pages 自动部署：
- 构建命令：`npm run build`
- 输出目录：`dist`
- Node 版本：18+
