# 公考资料分析速算训练

一个面向 PC 与移动端的纯前端速算练习工具。

## 功能

- 加减乘除预设训练与 1–4 位数自定义组合
- 除法使用分数形式展示
- 假设分配专项：根据现期量与增长率估算基期量或增长量
- 每题用时、正确率、错题解析和本地历史记录
- 除法与乘法估算沿用项目现有的前三位码判题规则

## 假设分配专项

- 四选一作答，求基期量与求增长量大致各半
- 每题最多尝试 20 个随机候选，失败后使用经过同等数学校验的保底构造器
- 题组平衡难度与 A–D 正确位置，并限制近期结构重复
- 错题展示 `A:X = 100:R`、首次分配、尾差、尾差再分配和合并结果

## 技术栈

- React 19
- TypeScript 7
- Vite 8
- Vitest 5
- 原生 CSS，无后端与新增运行时依赖

## 本地开发

```bash
npm install
npm run dev
npm run typecheck
npm run test
npm run build
```

Node.js 版本要求：`>=22.13.0`。

## 部署

项目通过 Cloudflare Pages 自动部署：

- 生产分支：`main`
- 构建命令：`npm run build`
- 输出目录：`dist`

详细步骤见 `DEPLOY.md`。
