# 公考速算产品规则

更新日期：2026-09-19  
状态：当前有效，修改判题或训练行为时必须同步更新本文件与测试。

## 四则运算判题

- 加法、减法、普通乘法：输入完整答案。
- 所有除法和“乘法估算”：输入前三位有效数字估算码。
- 前三位码从第一个非零有效数字开始，忽略小数点和前导零，直接截断、不四舍五入。
- 精确结果不足三位时不补零：`0.5 → 5`，`2.4 → 24`。
- 有效数字中间的零必须保留：`2.4059 → 240`。

## 估算容差

- 除法和“乘法估算”均允许 `±1%` 相对误差。
- 相对误差按前三位码还原后的估算数值与精确计算结果比较，不直接比较数字码。
- 码长度和数量级必须与参考码一致，避免 `5`、`50`、`500` 混用。
- 当前代码单一事实源位于 `src/core/checker.ts`：
  `ESTIMATION_RELATIVE_TOLERANCE_PERCENT`。
- 首页、练习提示和答题反馈必须从同一导出值生成，不得单独硬编码百分比。

## 练习流程

- 每道题独立计时，答题提交时立即停止该题计时。
- 普通算术题提交后展示对错，并在 300ms 后自动进入下一题。
- 假设分配题答错时停留并展示完整步骤，由用户确认后进入下一题。
- 除法题在练习、反馈、结果和历史记录中使用上下分数形式。
- PC 与移动端同等支持。

## 假设分配

- 当前只实现假设分配专项，不预建未实现的速算方法入口。
- 题目覆盖求基期量与求增长量，采用四选一作答。
- 约 80% 为宽间距题，约 20% 为近选项题；生成必须有有界尝试和数学安全校验。
- 增长率分布：约 85% 位于 1%–15%，约 15% 位于 >15%–25%。
- 小题组采用配额控制，确保接近该比例：十题组中较高增长率（>15%）只有 1 或 2 道。
- 增长率分布与选项间距难度、求解目标、正确选项位置相互独立。
